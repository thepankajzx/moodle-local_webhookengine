# Security Policy

## Reporting Security Issues

Definite Labs takes the security of its Moodle plugins seriously. If you discover a security vulnerability in `local_webhookengine`, please follow responsible disclosure guidelines.

### How to Report

Please do NOT file public issues on issue trackers. Instead, report vulnerabilities directly to our security team via email at:
`support@thedefinite.one`

Include the following details in your report:
- Plugin version.
- Moodle version and PHP environment.
- Step-by-step reproduction instructions or proof-of-concept.
- Potential impact of the issue.

We will acknowledge receipt within 48 hours and provide updates throughout the resolution process.
